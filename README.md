# AI動画編集のすゝめ — Codex Plugin

Premiere Proを起動せず、参照動画と手元の素材から、チャンネル固有の構成・カット・字幕・画角・画像・SE／BGMを設計し、編集と最終確認を進めるCodexプラグインです。

対応する編集系統は次の4つです。

- AI動画編集のすゝめ
- AI収益化ラボ
- AA／CC（AIエージェント／ClaudeCode）
- Instagram奥山ショート

指定外のYouTubeチャンネルは、同じチャンネルの異なる動画10本以上を時系列で確認し、入り・保持・戻しまで記録してから編集します。

## インストール

Codex CLIで公開マーケットプレイスを追加し、プラグインをインストールします。

```bash
codex plugin marketplace add fuuuuuuma/ai-video-editing-susume
codex plugin add ai-video-editing-susume@ai-video-editing
```

インストール後は新しいCodexタスクを開き、次のように呼び出します。

```text
$ai-video-editing-susume で動画を編集してください
```

Skillは最初に、4チャンネルまたは「その他のYouTube」のどれかを確認します。依頼文ですでに指定されている場合は再質問しません。

## できること

- 内容から説明、比較、Tier、ランキング、四象限、物語などの企画型を判定
- 無音だけに頼らず、言い直し、フィラー、待ち、意味のある間を全編で判断
- チャンネルごとの通常字幕、強調、話者色、画面収録中の表示方針を選択
- 人物映像と固定図を別レイヤーとして扱い、画角・画像・ワイプの寿命を設計
- SEの開始差、尾、BGMの継続・停止・復帰を個別に設計
- 編集計画、10本学習、字幕連続性を同梱スクリプトで検査

このプラグインはAdobe Premiere Proを自動操作しません。動画生成には、Codexが利用できるローカルのFFmpeg等と、利用者が権利を持つ素材が必要です。

## 「学習済み」の扱い

メタデータ、字幕、サムネイル、静止画、プロジェクト内の書式件数だけでは「全編視聴済み」「全編実聴済み」「完全再現済み」としません。各動画の全編視聴、音声確認、演出の入り・保持・戻し、短い再現出力、最終MP4の照合を別々に記録します。

公開版に含むチャンネル知識は、保存済みプロジェクトと公開映像から確認できた編集パターンです。4系統すべての全公開動画を全編実聴し、全演出を完全再現したという認定ではありません。現在の確認境界は[検証状態](https://ai-video-editing-susume.fuuuuuuma.dev/status.html)に明記しています。

## ドキュメント

チャンネル別の編集ルールと「その他のYouTube」の学習方法は、[公開サイト](https://ai-video-editing-susume.fuuuuuuma.dev/)で読めます。

## プライバシー

このリポジトリには、依頼素材、案件URL、個人のローカルパス、Premiereプロジェクト、字幕全文、動画・音源・フォントを含めていません。各案件で生成する分析・編集ファイルは利用者のローカル環境へ保存します。
