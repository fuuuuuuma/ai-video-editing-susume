編集の言語化

初期参照期間は2026-04-29より前。AAとCCは同じ系統ですが、実演、会話、比較、発表の型を分けます。

カット感

  1. 完成した言い直し、必要な例・対比・結論、デモ操作の因果を全文から特定。
  2. 捨てた言い直し、単独フィラー、撮影指示、不要な生成待ちを削除候補にする。
  3. 質問への応答、結果を読む間、注意前の溜め、感情の反応は残す。
  4. 接続前後の子音・母音・呼吸を声だけで確認する。

短縮した分数や無音件数ゼロを品質指標にしません。一律に詰めると、言葉は切れても説明のリズムが壊れます。

通常字幕

主話者は白文字＋深青、聞き手は緑系の実例。特定保存例はSource Han Sans JP Heavy、サイズ85、青 #0D3A66 の有効ストローク5とぼかした影。

  • 本編は通常字幕、強調、Pointのいずれかで連続表示する。
  • 強調終了後の字幕復帰まで空白を作らない。
  • 短い反応や重なる会話を主話者へ統合しない。
  • 画面収録にも通常字幕を出す型がある。
  • 保存されていても無効な背景・縁を有効化しない。

左2段帯

上段タイトルと下段小章を別スタイルとして校正します。

  • 上段はBold、下段はHeavyの観測例。通常字幕のHeavy一種類に潰さない。
  • 固定幅にせず、実文字幅と左右余白から帯幅を決める。
  • 背景、縁、影、上下位置を同じ参照文言で比較してから今回の文言へ差し替える。
  • 字幕やカメラカットをまたいで保持し、章変更時だけ下段を更新する。

強調・章

役割見た目時間の扱い
強い主張黄明朝＋寄り＋短いフラッシュ約10fの入りと字幕保持を分離
制限・弱い反応白明朝＋黒ぼかし鈴の残響を字幕尺で切らない
条件・注意赤明朝該当条件だけ。全否定へ拡張しない
要約黒帯＋黄Point＋白文通常字幕を置換して復帰
章間黒い立方体＋タイプ文字カーソル・キーボード音まで再現

画面・画像

  • 冒頭抜粋は説明文字、操作画面、完成結果を台詞に合わせて段階表示する。
  • ロゴ、プロフィール、赤枠、拡大鏡、入力中ラベルは対応対象の寿命で管理する。
  • 赤枠は入力欄→送信結果のようにUI状態へ追従する。
  • 画面収録の拡大と右上の円形ワイプを別変換にする。
  • 人物ワイプは灰系リングの実例。操作対象を隠さない。

SE／BGM

  • 強い結論、画像・ロゴ登場、テーマ提示、Point、章間を別のSEへ割り当てる。
  • 1種類の決定音や`キッ`へ統一しない。
  • 映像、字幕、SEの残響を同じ終端へ揃えない。
  • BGMは導入、本編、締めの意味境界で切り替える。章間ごとに曲を頭から再生し直さない。
  • 試聴・生成音声デモでは元音を優先する。

実装とQA

header / emphasis / camera / images / pip / se / bgm / ctaの8分野に、採否、参照、対応発話、開始・終了、実装IDを持たせます。

  • 計画したSE・画像が最終編集表に存在するか。
  • 字幕が途中で消えず、先出しされていないか。
  • 声のカット接続を実聴したか。
  • 左帯、画面収録、ワイプ、BGMを最終MP4で確認したか。
