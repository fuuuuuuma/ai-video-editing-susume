学習の言語化

本数を満たすための収集ではなく、今回の動画を編集できる判断表を作る工程です。

1. 範囲を固定

  • チャンネルURLからIDと表示名を確認する。
  • 転載、広告、コラボ相手の投稿、別チャンネルを混ぜない。
  • 期間指定があれば日付で絞る。なければ現行様式を中心にする。
  • 今回に近い単独、対談、実演、比較等を含める。

2. 10本を実見

異なる動画IDを10本以上選び、各動画の冒頭、通常説明、実演・図、強調、構成転換、終了を時間順に確認します。

タイトル、URL、サムネイル、字幕、章、ストーリーボードだけでは「視覚確認済み」にしません。

3. 各3場面を深掘り

通常→強調、図の更新、画面収録、章、終了案内などから最低3場面を選び、次を記録します。

  • 入る前（before）：通常状態
  • 開始（entry）：何がどの発話で入るか
  • 保持（hold）：何をどこまで残すか
  • 終了（exit）：何が消え、何へ戻るか
  • 字幕との関係（caption interaction）：通常字幕を置換するか重ねるか
  • 音の確認状態（audio status）：実聴、配置のみ、未確認

4. 6分野を分離

分野言語化する内容
構成導入、企画型、状態更新、構成転換、終了
カット削る言葉、残す間、操作・結果の因果
字幕書体、サイズ、色、縁、影、位置、話者、連続性
画角基本構図、寄る発話、戻る発話、変換対象
画像役割、実体、入り、保持、交換、退出
音SEの開始差と尾、BGMの継続・停止・復帰

5. 共通と例外

10本すべてに出る傾向、特定企画だけの型、古い様式、例外を分けます。プロジェクト値と画面からの推定値も分けます。

今回の主参照を1本選び、他の9本は不足部分や例外を補う参照として使います。

6. 編集へ接続

通常字幕、強調、画面収録、比較図、画像、ワイプ、SE、BGM、終了案内について、使う条件・使わない条件・入り・保持・戻りを今回の発話へ割り当てます。既知4チャンネルの書式を代用しません。

検査できる記録

動画ごとに視覚確認、全編視聴、実聴を別の真偽値として残します。

{ "id": "video-id", "channel_id": "channel-id", "visual_reviewed": true, "full_watch": false, "audio_reviewed": false, "temporal_reviews": [ { "start": 10.0, "end": 14.0, "before": "通常状態", "entry": "強調が入る", "hold": "字幕と寄りを保持", "exit": "通常へ戻る", "caption_interaction": "通常字幕を置換", "audio_status": "listened" } ] }

件数検査が通っても、本当に見たか、解釈が正しいか、フォントや音量が一致するかは別途確認します。
