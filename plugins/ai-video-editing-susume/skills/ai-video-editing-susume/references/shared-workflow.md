# 共通編集工程

## 1. 主参照を内容で選ぶ

話題の近さだけでなく、導入、比較軸、評価語、結果開示、手順への移行、CTAが今回の素材と同じ動画を主参照にする。途中の数秒だけで全編の型を決めない。

主参照の冒頭、本編、すべての構成転換、結果、終了を時間順に確認する。ランキング、Tier、固定比較表、四象限は別形式。混合型は`Tier → 手順 → CTA`のように区間で記録する。

## 2. 状態遷移を作る

比較図や手順カードは画像1枚として扱わず、次の状態を定義する。

1. 未紹介
2. 候補を提示
3. 評価・結果を確定
4. 確定済み結果を保持
5. 次候補へ交換
6. 内容の転換で図を撤去

人物のカットや字幕更新で、確定済みの結果を消さない。結果を発話前に表示しない。

## 3. カットの台帳

各判断に`source_start / source_end / action / before_words / after_words / reason / review_status`を持たせる。

- `remove_retake`: 捨てた発話と完成した言い直しを対で確認
- `remove_filler`: 語頭や意味のある反応でないことを実音で確認
- `remove_offtopic`: 撮影指示、再開合図、不要な脱線
- `shorten_wait`: 理解に不要な準備・生成待ち
- `keep_pause`: 評価前の溜め、質問後、読解、余韻
- `pending`: 音声や文脈が不足して判断不能

一律の無音秒数や短縮分数を品質指標にしない。

## 4. 字幕の状態

通常、強調、Point、引用、話者反応を1つの論理字幕レーンとして管理する。対象区間は常に1つ以上の字幕イベントで覆い、重複は同時発話等の根拠を持つ場合だけ許可する。

画面収録で字幕を隠す場合は、チャンネル規則と区間を明記する。ヘッダー、QR、資料内文字は字幕の代用にしない。

## 5. 独立レイヤー

人物映像、固定図、テーマ帯、字幕、資料、ワイプ、SE、BGMは別々の寿命を持つ。人物だけの寄り、資料の保持、字幕の置換、SEの尾、BGMの継続を同じ終端へ強制しない。

## 6. 確認用の短い合成

採用する書式ごとに前の通常状態、入り、最大状態、保持、戻り、次の通常状態を含める。静止画1枚やパラメータ一覧で再現完了としない。
