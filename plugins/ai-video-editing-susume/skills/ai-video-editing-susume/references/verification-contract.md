# 検証と完了条件

## 分けて記録する状態

| 状態 | 必要な証拠 |
|---|---|
| メタデータ確認 | URL、ID、公開日、尺、チャンネルID |
| 視覚確認 | 実動画または連続フレームの時刻、前後の状態 |
| 全編視聴 | 動画の全区間を連続して確認した記録 |
| 音配置確認 | タイムラインや計画上の音素材と時刻 |
| 実聴 | 音声を実際に聞いた区間と結果 |
| 再現確認 | 入り・保持・戻りを含む出力と参照の比較 |
| 最終確認 | 書き出したMP4全編の映像・音声・スマホ表示確認 |

静止画、字幕全文、ASR、波形、全フレームデコード、ファイル名、プロジェクト内のオブジェクト数は、全編視聴や実聴の代わりにならない。

## 「完全に学習済み」の条件

対象範囲を先に定義し、範囲内の全動画で次を満たす。

1. 全編視聴と全編実聴が記録されている。
2. 通常状態、強調、構成転換、画面収録、図、CTA、SE、BGMの全実例が索引化されている。
3. 各実例の入り、保持、戻り、字幕との関係、画角、音が記録されている。
4. 代表例ではなく全演出について短い再現出力を作り、映像と音を比較している。
5. 未確認、素材不足、推定、例外が0件、または対象範囲外として明示されている。
6. 最終MP4を全編確認し、発見した問題を修正後に再確認している。

いずれかが欠ける場合は「部分確認」「計画検査済み」「描画確認済み」等の実際の境界を報告する。

## 現在の公開知識の境界

同梱の4チャンネル資料は、保存済みプロジェクトと公開映像から確認できた編集パターンを言語化したもの。4系統の全公開動画について上記6条件を満たした認定データではない。Skillはこの不足を隠さず、案件ごとに採用する参照区間を再確認する。

## 最終MP4の検査

- 冒頭から終了まで、カット接続、字幕同期、画像、図、画角、音を確認
- 字幕対象区間の空白、先出し、透明、画面外、極端な短時間表示を確認
- 通常→強調→通常、図の更新・撤去、資料交換、ワイプの開始終了を境界前後で確認
- 声だけで切断音と残存無音を確認し、その後SE、BGMを重ねてミックスを確認
- PC表示と9:16／スマホ相当の縮小表示で視認性を確認

機械検査が通っても、意味判断と実視聴・実聴を省略しない。
